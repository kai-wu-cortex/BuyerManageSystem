# 供应商报价单导航整合设计

## 目标

只调整“供应商报价单”App 的内部布局，移除嵌套在系统主侧栏旁的第二层深色侧栏，使该模块看起来是采购管理系统中的同一个页面，而不是另一个嵌套应用。

## 页面结构

- 保留采购管理系统现有左侧主导航，不改动其他模块。
- 供应商报价单 App 改为单栏内容区，直接使用系统页面的浅色背景和白色卡片。
- “报价档案、产品分组、供应商评分、产品比价”放在页面标题下方，使用横向标签导航。
- “解析校对”继续作为报价档案的详情状态，不单独占用标签；详情页保留返回报价档案的操作。
- 刷新和上传报价单仍位于页面标题区域右侧。

## 视觉规则

- 沿用系统现有蓝色作为选中标签和主要交互色，避免内部模块另起一套深色与黄色导航体系。
- 标签允许横向滚动，窄屏不换成第二个侧栏。
- 去掉 App 外层过重的圆角容器和深色品牌区，使用轻边框、白色卡片和统一间距融入主内容区域。
- 功能内容、数据请求、报价解析和业务权限保持不变。

## 验收标准

1. 页面只显示系统主侧栏，不再显示供应商报价 App 的深色侧栏。
2. 四个一级功能可通过内容区顶部标签切换。
3. 报价校对可返回报价档案。
4. 上传、刷新、搜索、筛选及各业务视图行为不变。
5. TypeScript 检查和生产构建通过，Vercel Preview 页面可正常打开。
