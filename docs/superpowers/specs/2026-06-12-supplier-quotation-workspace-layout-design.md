# 供应商报价工作台布局设计

## 目标

参考用户提供的三张界面图，重构供应商报价 App 的解析校对、供应商评分和产品比价页面，使其更接近专业采购工作台。采购管理系统现有主侧栏保持唯一导航，不增加报价 App 内部侧栏。

## 全局结构

- 保留报价档案、产品分组、供应商评分、产品比价四个顶部标签。
- 使用深海军蓝、浅蓝灰背景、细边框和紧凑表格，减少圆角和装饰性阴影。
- 所有页面继续使用现有数据模型和保存接口，不新增虚假字段或演示数据。
- 空值、待校对字段和最低价使用明确的警示色或优势色。

## 解析校对

- 页面采用左右 50/50 分屏。
- 左侧包含原文件名称、预览区域和新窗口打开入口。Excel 使用工作表预览，PDF和图片使用原文件预览。
- 右侧顶部显示“解析校对页”、校对状态和完成度；下面排列供应商、报价单号、日期、币种、汇率、税率和付款方式。
- 产品明细使用紧凑可编辑表格，缺失字段所在行以浅黄色突出。
- 底部显示阻塞问题统计，并保留“保存草稿”和“确认并保存”操作。

## 供应商评分

- 左侧提供供应商列表，右侧展示当前选中的供应商档案。
- 档案顶部显示供应商名称、联系人信息和保存操作。
- 中部以四张评分卡展示质量、交期、服务和合作评分，包含数字、进度条和评分备注。
- 底部展示该供应商的历史报价记录，包括报价单、日期、产品摘要、状态和查看入口。

## 产品比价

- 顶部选择标准产品组，并通过复选按钮选择具体报价版本。
- 主体使用横向矩阵：第一列为评估指标，后续每列代表一个供应商报价版本。
- 指标包括标准化单价、MOQ、交期、付款条件、质量评分、交付评分和有效期。
- 每一行自动突出最优值：最低单价、最低 MOQ、最短交期及最高评分。
- 没有已确认产品组或标准化报价时，显示现有空状态提示。

## 验收标准

1. 不出现第二层侧栏。
2. 解析校对呈左右分屏并保留全部编辑、预览和保存能力。
3. 供应商评分可选择供应商、编辑四项评分与备注，并看到历史报价。
4. 产品比价呈供应商横向矩阵并突出最优指标。
5. 专项布局测试、TypeScript 检查和生产构建通过。
6. 新 Vercel Preview 可正常登录和打开供应商报价 App。
